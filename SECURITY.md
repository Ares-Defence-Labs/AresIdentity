# Security and privacy reporting

Report suspected vulnerabilities privately to team@aresdefencelabs.com. Describe affected version, platform, reproduction and impact using synthetic documents. Do not disclose keys, identity data or exploit details in a public issue. Never commit issuer private keys or sandbox-issued customer tokens. Sandbox trust must remain isolated from production artifacts.

OCR/classification is heuristic and does not establish authenticity. The host application owns consent, access control, storage, retention, transport and export review. Solid redaction returns newly encoded pixels; protect/delete original and temporary files separately.
