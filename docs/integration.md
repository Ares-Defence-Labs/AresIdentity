# AresIdentity integration

Start with [getting started](getting-started.md), then choose the [ready-made scanner](scanner-screen.md) or [embedded camera](embedded-camera.md). Capture callbacks receive `AresIdentityImage`; use `capture.bytes` for recognition and redaction.

Follow [recognition and redaction](recognition-and-redaction.md) for a complete asynchronous example, coordinate rules and licence forwarding. See the [public API reference](api-reference.md) and [platform setup](platforms.md) for configuration. The customer package is not published yet; [release status](release-status.md) lists the remaining verification gates.
